# Участие в разработке

Предложения, отчёты об ошибках и точечные улучшения приветствуются.

## Перед созданием Issue

1. Проверьте текущую версию программы.
2. Убедитесь, что проблема воспроизводится после перезапуска.
3. По возможности выполните встроенную диагностику/SELF-TEST.
4. Не прикладывайте реальный `data.json` и другие рабочие данные.

## Отчёт об ошибке

Укажите:

- версию СМЕНАРИУМ;
- ОС;
- последовательность действий;
- ожидаемый результат;
- фактический результат;
- обезличенный текст/скриншот ошибки.

## Изменения кода

Перед Pull Request желательно выполнить:

```bash
python -m py_compile app.py
python app.py --self-test
```

Если менялся JavaScript в `web/index.html`, выполните синтаксическую проверку Node.js аналогично процедуре из `TEST_REPORT_v0242.txt`.

Старайтесь не смешивать в одном PR рефакторинг и изменение пользовательской логики. Изменения генерации графика, расчёта часов, табелей, зарплаты, обновлений и защиты данных требуют регрессионной проверки.
