# Приватность и обработка данных

## Основной принцип

СМЕНАРИУМ — локальное приложение. Рабочие данные хранятся на компьютере пользователя в `data.json` и локальных папках программы.

Начиная с версии 0.2.45 штатный Windows-интерфейс по умолчанию открывается в отдельном desktop-окне через `pywebview`. При недоступности встроенного WebView программа может открыть обычный браузер. В обоих случаях backend остаётся локальным и привязан к `127.0.0.1`; это не превращает программу в облачный сервис.

## Что хранится локально

В зависимости от использования программы локально могут храниться:

- сведения об организации;
- карточки сотрудников и табельные номера;
- графики, план-графики, отпуска и отсутствия;
- параметры зарплаты и KPI;
- кадровые и профессиональные документы;
- резервные копии;
- сформированные отчёты и экспорты;
- настройки приложения.

Эти рабочие данные не предназначены для публикации в GitHub.

## Сетевые функции

СМЕНАРИУМ может обращаться в сеть для:

- обновления производственного календаря с `xmlcalendar.ru`;
- проверки и получения обновлений через собственный HTTPS-канал `armrukovoditel.ru/update`;
- добровольной отправки обезличенных технических ошибок на `armrukovoditel.ru`;
- открытия сайта проекта, онлайн-демо и внешних ссылок по явному действию пользователя.

Механизм обновлений не использует стороннее облачное SDK. Перед применением обновления проверяются размер и SHA-256, а Windows-сборка дополнительно использует системное хранилище доверенных сертификатов и `certifi`. Проверка TLS-сертификата и имени узла не отключается.

## Обновления и пользовательские данные

Обновление программы не должно заменять рабочий `data.json`.

Перед заменой Windows EXE механизм обновления сохраняет предыдущий исполняемый файл и `data.json` для rollback. Если новая версия не подтверждает успешный запуск через startup-marker, выполняется откат.

Журналы updater находятся в локальном каталоге `_updates` и предназначены для диагностики процесса обновления.

## Анонимные технические ошибки

Функция выключена по умолчанию и включается пользователем вручную.

Передаются только технические сведения, необходимые для группировки и диагностики сбоев, в частности:

- версия СМЕНАРИУМ;
- версии Python / NumPy / SciPy и тип ОС;
- тип ошибки;
- безопасное имя операции или HTTP-маршрута;
- имена функций/файлов исходного кода и номера строк;
- хэш сообщения об ошибке вместо исходного текста;
- случайный `session_id`, меняющийся при каждом запуске.

Не передаются:

- `data.json`;
- ФИО и табельные номера;
- название учреждения;
- графики и план-графики;
- отпуска и отсутствия;
- зарплата и KPI;
- локальные пути;
- имя пользователя Windows и имя компьютера;
- исходный текст исключения;
- постоянный идентификатор установки.

PHP-приёмник приложения не сохраняет IP-адрес в отчёт. При этом стандартные access-логи хостинга могут фиксировать IP независимо от приложения; это контролируется настройками хостинга.

## Обратная связь

Раздел «Связь и поддержка» формирует обращение только по инициативе пользователя. Техническая информация добавляется в текст только при явном выборе соответствующей опции. Данные сотрудников, зарплаты, график и реквизиты организации автоматически в обращение не включаются.

## GitHub

Перед созданием Issue, Pull Request или публикацией диагностических материалов удаляйте реальные персональные и рабочие данные. Не прикладывайте рабочий `data.json`.
