СМЕНАРИУМ v0.2.45
==================

Главное изменение: настольная оболочка программы.

- По умолчанию интерфейс открывается в отдельном окне СМЕНАРИУМ через pywebview.
- Локальный HTTP backend и вся существующая логика графиков сохранены без архитектурной переделки.
- В адресной строке/вкладке браузера пользователь больше не работает в штатном Windows-сценарии.
- Если встроенный WebView недоступен, программа автоматически переходит к обычному браузеру.
- Добавлены параметры --browser / --no-desktop и SMENARIUM_UI_MODE=browser для диагностики.
- Второй запуск Windows EXE пытается поднять уже открытое desktop-окно вместо новой вкладки.
- Внешние http/https/mailto ссылки из desktop-режима открываются системным браузером.
- На вкладке «Обновление» в desktop-режиме есть кнопка «Открыть во внешнем браузере».
- Перезапуск, автообновление и rollback закрывают desktop-окно и позволяют updater завершить текущий процесс.
- Windows-сборка сохраняет полноценные stdout/stderr для внутренних процессов, но при обычном запуске собственное консольное окно скрывается загрузчиком PyInstaller.
- В сборку включён модуль desktop_shell.py и зависимости pywebview.

Безопасность данных
-------------------
Desktop-оболочка не превращает программу в облачный сервис. Интерфейс загружается с локального адреса 127.0.0.1, а пользовательская база продолжает храниться локально в каталоге данных СМЕНАРИУМ.

Исправление TLS обновлений
--------------------------
- Исправлен CERTIFICATE_VERIFY_FAILED / self-signed certificate in certificate chain в Windows-сборках, когда браузер доверяет сертификату через системное хранилище Windows, а встроенный Python/OpenSSL — нет.
- Проверка сертификата и имени узла НЕ отключается.
- Контекст TLS объединяет стандартные корневые сертификаты, certifi CA bundle и доверенные сертификаты Windows ROOT/CA.
- SHA-256 и контроль размера пакета остаются обязательными.
- Добавлена диагностическая команда --update-live-check.
