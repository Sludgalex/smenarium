## Приватность и локальная архитектура

Рабочий файл `data.json`, резервные копии, экспорты и вложения находятся на локальном компьютере. Браузер подключается к приложению через `127.0.0.1`.

Сетевые обращения возможны только для отдельных функций:

1. обновление производственного календаря с `xmlcalendar.ru`;
2. проверка/получение обновлений программы из публичных папок MEGA;
3. добровольная отправка обезличенных технических ошибок — **выключена по умолчанию**.

При включённой отправке ошибок `data.json`, ФИО, табельные номера, название учреждения, графики, отпуска, зарплата, KPI, локальные пути, имя пользователя Windows и постоянный идентификатор установки не отправляются. Подробности: [`PRIVACY.md`](PRIVACY.md).

## Установка и запуск

### Windows — из исходников

1. Установите Python 3.8+.
2. Скачайте или клонируйте репозиторий.
3. Запустите `start_windows.bat`.
4. При первом запуске будет создано локальное окружение `.venv` и установлены зависимости.
5. Браузер откроется автоматически.

### Linux

```bash
chmod +x start_linux.sh
./start_linux.sh
```

Зависимости перечислены в [`requirements.txt`](requirements.txt).

### Windows ONEFILE

Для сборки одного EXE используется `build_exe_windows.bat` и `SMENARIUM.spec`. Готовая сборка при обычном запуске размещает рабочую копию в `C:\SMENARIUM\SMENARIUM.exe`, а пользовательские данные хранит отдельно от EXE.

## Обновление без потери базы

- рабочий `data.json` не входит в корень поставки;
- `defaults/data.json` — только стартовый шаблон для новой установки;
- существующий `C:\SMENARIUM\data.json` не должен заменяться обновлением;
- при необходимости программа проверяет предыдущую установку и резервные копии;
- перед обновлением/структурными операциями создаются защитные копии.

## Безопасность данных

Не публикуйте рабочий `data.json`, реальные резервные копии, кадровые выгрузки, табели или диагностические архивы с рабочими данными. `.gitignore` этого репозитория специально исключает основные runtime-каталоги.

Сообщения об ошибках и предложения можно оформлять через GitHub Issues без персональных/рабочих данных. Для уязвимостей и вопросов приватности см. [`SECURITY.md`](SECURITY.md).
