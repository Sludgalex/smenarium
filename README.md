# СМЕНАРИУМ

**СМЕНАРИУМ** — бесплатная локальная программа для составления и контроля графиков смен, планирования отпусков, ведения табелей рабочего времени, контроля покрытия постов, аналитики, KPI и предварительного расчёта заработной платы.

**Актуальная версия:** 0.2.47 · **дата версии:** 31.08.2026

## Локальная программа, а не облачный сервис

СМЕНАРИУМ использует локальный HTTP-backend на `127.0.0.1`, но это не означает хранение рабочей базы в интернете.

Начиная с версии **0.2.45** в Windows штатный интерфейс по умолчанию открывается в отдельном desktop-окне через `pywebview`. Если встроенный WebView недоступен, программа автоматически использует обычный браузер как резервный интерфейс.

Основная рабочая база, резервные копии, экспорты и вложения остаются на компьютере пользователя.

## Что нового в 0.2.47

Главная задача версии — исправить Windows-сценарий, при котором обновление находилось и скачивалось, СМЕНАРИУМ закрывался, но рабочий EXE не заменялся либо после запуска оставалась предыдущая версия.

- перед обновлением гарантированно завершается постоянный `optimizer-daemon`;
- внешний PowerShell-updater запускается отдельно от основного процесса;
- updater ждёт освобождения `C:\SMENARIUM\SMENARIUM.exe` и повторяет замену при временной файловой блокировке;
- дополнительно завершаются зависшие процессы, использующие тот же рабочий EXE;
- SHA-256 проверяется до и после замены файла;
- новая версия должна подтвердить успешный запуск через `startup-marker`;
- при отсутствии подтверждения выполняется rollback;
- результат обновления записывается в `C:\SMENARIUM\_updates\last_update_result.json`;
- подробный журнал сохраняется в `C:\SMENARIUM\_updates\update_apply.log`;
- автообновление всегда нацелено на стабильный `C:\SMENARIUM\SMENARIUM.exe`;
- для единственного перехода со сборок со старым неисправным updater добавлен отдельный безопасный repair-механизм;
- рабочий `data.json` обновлением не заменяется.

Полный список: [`CHANGELOG_v0247.txt`](CHANGELOG_v0247.txt).

## Обновления

Начиная с 0.2.44 механизм обновлений использует собственный HTTPS-канал проекта вместо публичных папок MEGA.

Перед применением обновления проверяются:

1. доступность и структура `latest.json`;
2. размер пакета;
3. SHA-256;
4. для Windows one-file — версия и health-check;
5. после запуска — `startup-marker` новой версии.

При сбое замены или запуска выполняется безопасный откат. Рабочие данные пользователя не должны заменяться пакетом обновления.

Для перехода со старой версии, updater которой уже проявил ошибку «скачалось, закрылось, но не обновилось», см. [`BUILD_AND_REPAIR_v0247.txt`](BUILD_AND_REPAIR_v0247.txt).

## Приватность и сетевые обращения

Основные рабочие данные хранятся локально. Сеть используется только для отдельных функций:

1. производственный календарь с `xmlcalendar.ru`;
2. проверка и получение обновлений через `armrukovoditel.ru/update`;
3. добровольная отправка обезличенных технических ошибок;
4. открытие сайта, онлайн-демо и внешних ссылок по действию пользователя.

Обратная связь не отправляется скрыто. Техническая информация добавляется в обращение только по выбору пользователя; данные сотрудников, зарплаты, график и реквизиты организации автоматически не включаются.

Подробности: [`PRIVACY.md`](PRIVACY.md).

## Установка и запуск из исходников

### Windows

1. Установите Python 3.8+.
2. Скачайте или клонируйте репозиторий/исходный комплект.
3. Запустите `start_windows.bat` для создания или обновления `.venv`.
4. Для one-file сборки используйте `build_exe_windows.bat`.
5. В штатном режиме интерфейс откроется в отдельном окне СМЕНАРИУМ; при недоступности WebView будет использован браузер.

### Linux

```bash
chmod +x start_linux.sh
./start_linux.sh
```

Актуальные зависимости перечислены в [`requirements.txt`](requirements.txt). Для desktop-оболочки используется `pywebview`, для TLS-цепочки updater — `certifi` вместе с системным доверием Windows.

## Обновление без потери базы

- рабочий `data.json` не входит в корень поставки;
- `defaults/data.json` используется только как стартовый шаблон для новой установки;
- существующий `C:\SMENARIUM\data.json` не должен заменяться обновлением;
- перед заменой EXE сохраняются предыдущий EXE и `data.json` для rollback;
- защитные копии создаются также перед структурными операциями программы.

## Безопасность данных

Не публикуйте рабочий `data.json`, реальные резервные копии, кадровые выгрузки, табели или диагностические архивы с рабочими данными.

Сообщения об ошибках и предложения можно оформлять через GitHub Issues без персональных/рабочих данных. Для вопросов приватности и уязвимостей см. [`SECURITY.md`](SECURITY.md).
