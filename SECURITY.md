# Security Policy

## Поддерживаемая версия

В первую очередь исправления безопасности и защиты данных относятся к текущей версии СМЕНАРИУМ. На момент публикации — `0.2.42`.

## Как сообщить о проблеме

Если проблема не содержит чувствительных данных, создайте GitHub Issue с:

- версией СМЕНАРИУМ;
- версией Windows/Linux;
- краткими шагами воспроизведения;
- ожидаемым и фактическим результатом;
- обезличенным диагностическим материалом, если он нужен.

Не публикуйте в Issue:

- рабочий `data.json`;
- ФИО сотрудников;
- реальные табели, зарплаты, KPI;
- резервные копии;
- токены, пароли или иные секреты.

Для уязвимостей, которые нельзя безопасно раскрывать публично, используйте контакты автора на сайте проекта: https://armrukovoditel.ru/

## Локальная PIN-защита

PIN в СМЕНАРИУМ предназначен для ограничения случайного локального доступа. Он не заменяет системную учётную запись Windows/Linux, шифрование диска, BitLocker/LUKS и обычные меры физической безопасности рабочего места.
