# СМЕНАРИУМ v0.2.47

Дата версии: **31.08.2026**

Версия 0.2.47 исправляет Windows-сценарий, при котором обновление находилось и скачивалось, приложение закрывалось, но рабочий EXE не заменялся либо после запуска оставалась предыдущая версия.

## Основные изменения

- перед обновлением гарантированно завершается постоянный `optimizer-daemon`;
- внешний PowerShell-updater запускается отдельно от основного процесса;
- updater ждёт освобождения `C:\SMENARIUM\SMENARIUM.exe` и повторяет замену при временной блокировке Windows или антивирусом;
- дополнительно завершаются зависшие процессы, использующие тот же рабочий EXE;
- SHA-256 проверяется до и после замены файла;
- новая версия должна подтвердить успешный запуск через `startup-marker`;
- при отсутствии подтверждения выполняется rollback;
- результат применения сохраняется в `C:\SMENARIUM\_updates\last_update_result.json`;
- подробный журнал сохраняется в `C:\SMENARIUM\_updates\update_apply.log`;
- автообновление всегда нацелено на стабильный `C:\SMENARIUM\SMENARIUM.exe`;
- добавлен безопасный одноразовый repair-механизм для перехода со старых сборок с неисправным updater;
- пользовательский `data.json` при обновлении не заменяется.

## Важное примечание для обновления со старых сборок

Если старая установленная версия уже проявляет ошибку «скачалось, закрылось, но не обновилось», её updater не может исправить сам себя. Для первого перехода на 0.2.47 используйте `REPAIR_UPDATE_WINDOWS.bat` из актуального исходного комплекта. После успешного перехода последующие обновления должны снова выполняться штатно из интерфейса СМЕНАРИУМ.

Подробнее: [`BUILD_AND_REPAIR_v0247.txt`](BUILD_AND_REPAIR_v0247.txt).
